# Steuer-Kompass

Interview-Assistent zur Schätzung der Einkommensteuer (2024/2025): https://steuer.kompassapps.de

Reine Browser-App ohne Server. Eingaben bleiben im Browser des Nutzers. Die Beispieldaten (Familie Mustermann) sind erfunden.

Schätzung ohne Gewähr, keine Steuerberatung, keine Übermittlung an das Finanzamt.

Tests: `node --test tax.test.js`
